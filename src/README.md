# Hundred Cannons source

Editable source for the game served from `../hl-game.js`.
`python3 build.py` (run in this folder) concatenates the parts into `index.html` (local mode) and `hl-game.js` (Webflow embed).
Login emails and Supabase keys live in the Webflow page config, not here. Local-mode password hashes are blanked.
